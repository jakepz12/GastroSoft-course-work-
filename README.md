# GastroSoft

Desktop-приложение для автоматизации ресторана на Python 3.14+ и PySide6 (Qt 6). Работает с MySQL или в демо-режиме.

## Запуск

```bash
python -m pip install -r requirements.txt
python run_gastrosoft.py
```

## Подключение MySQL

1. Скопируй `mysql_config.example.json` → `mysql_config.json`
2. Заполни `host`, `port` (по умолчанию 3307), `user`, `password`, `database`
3. Создай схему: `python mysql_connection.py --init`
4. Заполни тестовыми данными: `python sql/seed_meaningful_data.py`
5. Проверь соединение: `python mysql_connection.py --test-db`

Если MySQL недоступен, приложение работает на демо-данных (пустые коллекции).

## Доступ по ролям

| Роль | Страницы | Возможности |
|------|----------|-------------|
| Директор | Все | Полный доступ |
| Шеф-повар | Кухня, Заказы, Отчёты | Назначение поваров, приоритеты, статистика |
| Повар | Кухня | Приготовление, отметка готовности |
| Официант | Заказы | Создание, примечания, закрытие выданных |
| Менеджер зала | Бронирования, Заказы | Управление посадкой |
| Бухгалтер | Склад | Складские операции и отчёты |

## Модули приложения

### Авторизация
Вход по логину/паролю. Регистрация новых сотрудников с выбором роли.

### Главная панель (Dashboard)
KPI-карточки (выручка, заказы, брони, остатки, среднее время кухни), графики продаж и популярных блюд, быстрые действия.

### Заказы (Официант)
- **Меню** — выбор блюд по категориям с вводом количества
- **Текущий заказ** — черновик с примечаниями, столом и способом оплаты
- **Заказы** — очередь с фильтрами, закрытие выданных заказов

### Кухня (Шеф-повар / Повар)
- Карточки заказов с таймерами (цветовая индикация: зелёный <10 мин, жёлтый <20, красный >20)
- Фильтр «Все активные» / «Мои заказы» (для повара)
- Назначение повара на заказ (шеф-повар)
- Приоритет «Срочно» / «Обычный»
- Поштучная отметка готовности блюд
- Отмена заказов
- Автообновление таймеров каждые 30 сек
- Уведомления о новых заказах

### Отчёты (Шеф-повар)
- Среднее время приготовления, количество выполненных/срочных/в работе
- Выручка за сегодня
- История заказов с деталями состава
- Текстовый отчёт с экспортом в файл

### Бронирования
Форма брони, карта столов (занят/свободен), список бронирований с изменением статусов.

### Смены и персонал
Список сотрудников, назначение на смены, подбор замены, закрытие смен.

### Склад
Остатки ингредиентов, операции (поступление/списание/корректировка), журнал, текстовый отчёт с экспортом.

## Структура проекта

```
GastroSoft-course-work--main/
├── run_gastrosoft.py              # Точка входа
├── gastrosoft_mysql.sql           # SQL-схема базы данных
├── mysql_connection.py            # Менеджер подключения к MySQL
├── mysql_config.json              # Конфигурация подключения
├── requirements.txt               # Зависимости (PySide6, mysql-connector-python)
├── gastrosoft_app/
│   ├── app.py                     # Инициализация QApplication
│   ├── shell.py                   # Главное окно и навигация
│   ├── mysql_store.py             # Слой данных (вся логика БД)
│   ├── data.py                    # DemoStore — заглушка без MySQL
│   ├── role_access.py             # RBAC: доступ ролей к страницам
│   ├── widgets.py                 # Переиспользуемые виджеты
│   ├── style_utils.py             # Загрузка QSS-стилей
│   ├── pages/
│   │   ├── auth_page.py           # Авторизация
│   │   ├── dashboard_page.py      # Главная панель
│   │   ├── orders_page.py         # Заказы (официант)
│   │   ├── kitchen_page.py        # Кухня (шеф/повар)
│   │   ├── reports_page.py        # Отчёты (шеф-повар)
│   │   ├── reservations_page.py   # Бронирования
│   │   ├── staff_page.py          # Смены
│   │   └── inventory_page.py      # Склад
│   └── styles/                    # QSS-стили для каждой страницы
└── sql/
    └── seed_meaningful_data.py    # Заполнение БД тестовыми данными
```

## Стек технологий

- **Язык:** Python 3.14+
- **GUI:** PySide6 (Qt 6)
- **БД:** MySQL 8 / MariaDB (опционально)
- **Стили:** QSS (Qt Style Sheets)
- **Хеширование:** SHA-256
