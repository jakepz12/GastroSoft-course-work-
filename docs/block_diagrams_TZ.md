# ТЗ на блок-схемы по ГОСТ 19.701-90

## Обозначения по ГОСТ 19.701-90

- **Овал** — начало/конец процесса
- **Прямоугольник** — процесс (действие)
- **Ромб** — условие (да/нет)
- **Параллелограмм** — ввод/вывод данных
- **Стрелки** — направление потока

---

## Блок-схема 1. Оформление заказа официантом

### Фигуры (сверху вниз):

1. **Овал** "Начало"
2. **Стрелка ↓**
3. **Прямоугольник** "Официант открывает страницу заказов"
4. **Стрелка ↓**
5. **Прямоугольник** "Выбор категории меню"
6. **Стрелка ↓**
7. **Прямоугольник** "Выбор блюда из списка"
8. **Стрелка ↓**
9. **Прямоугольник** "Ввод количества (1-99)"
10. **Стрелка ↓**
11. **Прямоугольник** "Добавление примечания (необязательно)"
12. **Стрелка ↓**
13. **Прямоугольник** "Нажатие «Добавить в заказ»"
14. **Стрелка ↓**
15. **Ромб** "Ещё блюда?"
    - **Да** → стрелка вверх к п.5 (Выбор категории)
    - **Нет** → стрелка вниз
16. **Прямоугольник** "Выбор стола"
17. **Стрелка ↓**
18. **Прямоугольник** "Выбор способа оплаты"
19. **Стрелка ↓**
20. **Прямоугольник** "Нажатие «Передать на кухню»"
21. **Стрелка ↓**
22. **Ромб** "Данные корректны?"
    - **Нет** → **Параллелограмм** "Сообщение об ошибке" → стрелка вверх к п.16
    - **Да** → стрелка вниз
23. **Прямоугольник** "Сохранение заказа в MySQL"
24. **Стрелка ↓**
25. **Прямоугольник** "Статус заказа: Принят"
26. **Стрелка ↓**
27. **Прямоугольник** "Статус позиций: В очереди"
28. **Стрелка ↓**
29. **Прямоугольник** "Оповещение кухни о новом заказе"
30. **Стрелка ↓**
31. **Овал** "Конец"

## Блок-схема 3. Приготовление поваром

### Фигуры:

1. **Овал** "Начало"
2. **Стрелка ↓**
3. **Прямоугольник** "Повар открывает кухонную панель"
4. **Стрелка ↓**
5. **Прямоугольник** "Фильтр «Мои заказы»"
6. **Стрелка ↓**
7. **Ромб** "Есть назначенные заказы?"
   - **Нет** → **Прямоугольник** "Ожидание" → стрелка вверх к п.5
   - **Да** → стрелка вниз
8. **Прямоугольник** "Выбор заказа"
9. **Стрелка ↓**
10. **Прямоугольник** "Нажатие «Взять в работу»"
11. **Стрелка ↓**
12. **Прямоугольник** "Статус заказа: Готовится"
13. **Стрелка ↓**
14. **Прямоугольник** "started_at = текущее время"
15. **Стрелка ↓**
16. **Прямоугольник** "Приготовление блюда"
17. **Стрелка ↓**
18. **Ромб** "Блюдо готово?"
    - **Нет** → стрелка вверх к п.16
    - **Да** → стрелка вниз
19. **Прямоугольник** "Нажатие «Готово: Блюдо»"
20. **Стрелка ↓**
21. **Прямоугольник** "Статус позиции: Готово"
22. **Стрелка ↓**
23. **Прямоугольник** "ready_at = текущее время"
24. **Стрелка ↓**
25. **Ромб** "Все позиции готовы?"
    - **Нет** → стрелка вверх к п.16 (следующее блюдо)
    - **Да** → стрелка вниз
26. **Прямоугольник** "Статус заказа: Готов"
27. **Стрелка ↓**
28. **Прямоугольник** "Оповещение официанта"
29. **Стрелка ↓**
30. **Овал** "Конец"

## Блок-схема 7. Просмотр отчётов

### Фигуры:

1. **Овал** "Начало"
2. **Стрелка ↓**
3. **Прямоугольник** "Шеф-повар открывает страницу «Отчёты»"
4. **Стрелка ↓**
5. **Прямоугольник** "Загрузка статистики из MySQL"
6. **Стрелка ↓**
7. **Параллелограмм** "Вывод KPI-карточек (среднее время, выполнено, срочных, выручка)"
8. **Стрелка ↓**
9. **Прямоугольник** "Загрузка истории заказов"
10. **Стрелка ↓**
11. **Параллелограмм** "Вывод таблицы истории"
12. **Стрелка ↓**
13. **Ромб** "Выбран заказ?"
    - **Нет** → стрелка к п.15
    - **Да** → **Прямоугольник** "Загрузка состава заказа" → **Параллелограмм** "Вывод позиций" → стрелка к п.15
14. **Прямоугольник** "Генерация текстового отчёта"
15. **Стрелка ↓**
16. **Ромб** "Экспортировать?"
    - **Да** → **Прямоугольник** "Сохранение в exports/kitchen_report.txt"
    - **Нет** → стрелка вниз
17. **Овал** "Конец"
