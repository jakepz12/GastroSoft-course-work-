# Разработка интерфейса кухонного модуля GastroSoft

## Выбранный стек интерфейса

Для реализации desktop-приложения на Python в проекте используется **PySide6**. Этот фреймворк подходит для кухонного модуля, потому что предоставляет готовые компоненты для настольного интерфейса: таблицы, кнопки действий, карточки, выпадающие списки, статусные метки и панель навигации.

## Обоснование выбора

PySide6 — это официальная Python-обёртка над Qt 6. Основные преимущества для данного проекта:

- Кроссплатформенность (macOS, Windows, Linux)
- Нативный вид виджетов на каждой ОС
- Мощная система стилей QSS (Qt Style Sheets)
- Встроенная поддержка таблиц, кнопок, выпадающих списков
- Сигналы и слоты для обработки событий

## Архитектура экранов

Каждая страница приложения реализована как отдельный класс QWidget:

- `AuthPage` — экран авторизации и регистрации
- `DashboardPage` — главная панель с KPI и графиками
- `OrdersPage` — оформление заказов (официант)
- `KitchenPage` — кухонная панель (шеф-повар, повар)
- `ReportsPage` — отчёты кухни (шеф-повар)
- `ReservationsPage` — бронирования
- `StaffPage` — смены и персонал
- `InventoryPage` — склад и отчёты

## Навигация

Навигация реализована через `QStackedWidget` в `shell.py`. Боковая панель содержит кнопки для каждой доступной роли. При входе в систему определяется роль пользователя и показываются только доступные ему страницы.

## Стилизация

Для каждой страницы используется отдельный QSS-файл в папке `styles/<page>/style.css`. Общая палитра:

- Фон: `#F8FAFC`
- Акцент: `#1F686E`
- Текст: `#1E293B`
- Успех: `#0F766E`
- Предупреждение: `#F59E0B`
- Опасность: `#991B1B`
